# 🎭 Mafia Online — Backend API

Серверная часть веб-приложения Mafia Online. Отвечает за авторизацию игроков, хранение комнат, контроль таймеров фаз (45 секунд) и расчет игровой логики на стороне сервера.

## Ссылка на рабочую версию
* **API Endpoint:** mafiaonline-limtfx.msk1.amvera.tech/api
* **Frontend репозиторий:** https://github.com/LimTFX/mafia-online-client

## Стек технологий
* **Node.js + Express:** REST API и настройка CORS.
* **SQLite3:** Локальная реляционная база данных для сохранения аккаунтов, токенов сессий и состояния комнат.

## Структура проекта
```text
├── server.js           # Точка входа Express-сервера и маршруты API
├── db.js               # Инициализация SQLite и схема таблиц
├── gameEngine.js       # Игровой движок (раздача ролей, таймер 45 сек, ночные ходы и голосование)
└── package.json        # Зависимости проекта
```
